## 一、文档关键事实

- **方法/路径**：`GET /track/getTrackList`，鉴权走 Header `key`（secret key），**不是** token。
- **必填 Query 参数**（全部 required）：`filterTime`、`stopStatus`、`posStatus`、`beginTime`(yyyy-MM-dd HH:mm:ss)、`endTime`、`queryType`、`queryParam`。
- **queryType 语义（最关键）**：`0` = 按**设备名**查询；`1` = 按**设备ID**查询。`queryParam` 相应填 设备名 或 设备ID。
- **时间跨度**：单次限**单设备**，**最多 7 天**。
- **限流**：每用户 **2 次/分钟**，超限触发限流。
- **成功响应**：`code=200`，`data.baseInfo`（plate/terminalNo…）、`data.trackList[]`、`data.trackTotal`。
- **失败示例**：`code=400`，`msg="The query period cannot exceed 7 days"`。

## 三、额外发现（来自 conftest.py）

- `send_api` 的 `path_params` 处理写错：`kwargs.pop("endpoint_key")`（conftest.py:134，以及 api_client:218），应为 `kwargs.pop("path_params")`。当前无人传 `path_params`，故潜伏；一旦用上即 `KeyError`。
- `real_time_location` 用 `POST` + `params=`，POST 下 `params` 进 **query 而非 body**，需确认该接口契约（本文档未覆盖此接口）。
